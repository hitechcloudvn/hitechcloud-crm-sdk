# Đóng góp

> [English](CONTRIBUTING.md) | **Tiếng Việt**

---

Cảm ơn bạn quan tâm đến việc cải thiện HiTechCloud CRM SDK.

## Cấu trúc kho mã

```
sdk/nodejs    TypeScript SDK  (@hitechcloudvn/crm-sdk)
sdk/python    Python SDK      (hitechcloud-crm)
sdk/php       PHP SDK         (hitechcloudvn/crm-sdk)
sdk/go        Go SDK          (github.com/hitechcloudvn/hitechcloud-crm-sdk/go)
sdk/java      Java SDK        (vn.hitechcloud:crm-sdk)
mcp           Node.js MCP server
docs          Bilingual documentation
examples      Runnable examples per language
openapi.json  OpenAPI 3.0.3 specification (generated by scripts/gen_openapi.py)
```

## Nguồn sự thật

Mọi endpoint được suy ra từ tham chiếu API CRM công khai
(`https://developers.hitechcloud.vn`). Khi API thay đổi, cập nhật
`scripts/gen_openapi.py`, tạo lại `openapi.json`, rồi nhân rộng thay đổi đó vào
SDK của từng ngôn ngữ.

```bash
python3 scripts/gen_openapi.py
```

## Quy trình phát triển

1. Fork kho mã và tạo một nhánh feature.
2. Thực hiện thay đổi trong **tất cả** SDK của các ngôn ngữ để chúng luôn đồng bộ.
3. Giữ tên phương thức công khai và accessor tài nguyên giống nhau giữa các
   ngôn ngữ, trong phạm vi quy ước của từng ngôn ngữ cho phép.
4. Thêm hoặc cập nhật test và ví dụ.
5. Chạy các bước kiểm tra theo từng ngôn ngữ bên dưới.
6. Mở một pull request mô tả thay đổi.

## Kiểm tra cục bộ

```bash
# Python
cd sdk/python && python -m py_compile hitechcloud_crm/*.py && pytest

# Node.js / TypeScript
cd sdk/nodejs && npm install && npm run build && npm test

# PHP
cd sdk/php && php -l src/Client.php && composer test

# Go
cd sdk/go && gofmt -l . && go vet ./... && go test ./...

# Java
cd sdk/java && mvn -q test
```

## Nguyên tắc viết mã

- Không dùng thư viện bên ngoài nào ngoài HTTP client được ghi trong tài liệu
  của từng ngôn ngữ.
- Không bao giờ log access token, client secret hoặc webhook secret.
- Giữ nguyên ngữ nghĩa của envelope phản hồi `status` / `data` / `meta`.
- Dùng `code` (không phải `message`) cho xử lý lỗi bằng chương trình.

## Giấy phép

Khi đóng góp, bạn đồng ý rằng các đóng góp của mình được cấp phép theo giấy
phép MIT, giống như phần còn lại của dự án.
